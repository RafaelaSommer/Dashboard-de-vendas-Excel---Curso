## 🚀 Sobre o projeto

Este projeto consiste no desenvolvimento de um **Dashboard de Vendas do Xbox Game Pass utilizando o Microsoft Excel**, como parte de um desafio prático da DIO.

O objetivo é transformar dados em informações visuais, facilitando a análise dos principais indicadores de assinaturas, receitas e renovações, por meio de um painel organizado, intuitivo e dinâmico.

## 📊 Indicadores apresentados

O dashboard apresenta uma visão geral do desempenho das assinaturas:

- 👥 **Total de assinantes:** quantidade de assinantes.
- 💰 **Receita total:** valor total da receita apresentada.
- 🎟️ **Total de cupons:** valor total relacionado aos cupons.
- 🔄 **Renovação automática:** percentual de renovação automática.
- 📦 **Assinantes por plano:** distribuição entre os planos Annual, Monthly e Quarterly.
- 📈 **Receita por plano:** comparação entre Core, Standard e Ultimate.

## 🛠️ Ferramentas utilizadas

- **Microsoft Excel** — organização e análise dos dados.
- **Gráficos** — representação visual dos indicadores.
- **Dashboard e KPIs** — consolidação das informações para facilitar a interpretação dos resultados.

## 🎯 Objetivo do desafio

Praticar habilidades de análise e visualização de dados, organização de informações e construção de dashboards, desenvolvendo uma apresentação visual clara e profissional.

## 💡 Principais aprendizados

- Estruturação de indicadores relevantes para análise.
- Criação e organização de gráficos no Excel.
- Transformação de dados em informações visuais.
- Desenvolvimento de um dashboard com foco em clareza e usabilidade.

## 📷 Visualização do projeto

O dashboard reúne os principais indicadores de assinaturas e receitas do Xbox Game Pass em um único painel visual.
